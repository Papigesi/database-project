# 2024-2025 Introduction to databases Course Term Project (E-Commerce)

This repository contains the term project for the **2024-2025 Introduction to Databases** course, focused on an e-commerce system.

## Contents

- **Project report (.pdf)**: Includes the full documentation of the project.
- **SQL Scripts (.txt)**:
  - **DDL**: Table creation statements
  - **Triggers**
  - **DML**: Insert, Update, and Delete operations
  - **SELECT**: Example queries to retrieve data

All SQL-related files are saved as `.txt` files for readability and compatibility.
